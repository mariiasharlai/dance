# Photos to drop in

This folder is empty on purpose. The cloud agent cannot read
`/Users/mariiasharlai/Desktop/DanceSharlai` on the owner's Mac.

Place WebP (preferred), JPG, or PNG files here using the exact slot names
below. The theme shows a purple studio placeholder until the file exists.
Do not commit photos of identifiable children without a Yes in the photo
consent field.
